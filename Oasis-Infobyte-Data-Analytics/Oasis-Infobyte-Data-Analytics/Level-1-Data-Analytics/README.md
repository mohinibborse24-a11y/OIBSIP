# Level 1 – Data Analytics Tasks

This folder contains the Level 1 projects completed as part of the Oasis Infobyte Data Analytics Internship Program.

## Tasks

### Task 1: Exploratory Data Analysis on Retail Sales Data
- Perform data cleaning and preprocessing.
- Analyze retail sales trends and customer demographics.
- Create visualizations to identify business insights.

### Task 2: Customer Segmentation Analysis
- Perform customer analysis using RFM metrics.
- Apply K-Means clustering to identify customer segments.
- Visualize customer groups and provide business recommendations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
