# Level 2 – Data Analytics Tasks

This folder contains the Level 2 projects completed as part of the Oasis Infobyte Data Analytics Internship Program.

## Tasks

### Task 1: House Price Prediction Using Linear Regression

- Perform data cleaning and preprocessing.
- Explore house price data using Exploratory Data Analysis (EDA).
- Build a Linear Regression model to predict house prices.
- Evaluate model performance using MSE, RMSE, and R2 score.

### Task 2: Wine Quality Prediction Using Machine Learning

- Perform data cleaning and preprocessing on wine quality data.
- Analyze wine features using Exploratory Data Analysis (EDA).
- Apply feature engineering and classification techniques.
- Train and compare Random Forest, SGD Classifier, and Support Vector Classifier (SVC).
- Evaluate model performance using accuracy, precision, recall, and F1-score.
- Predict wine quality for a new sample.
